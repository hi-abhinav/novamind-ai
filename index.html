    About this prototype

    NovaMind AI is an early-stage project prototype. Without a configured Gemini API key, it uses a clearly labelled demo planner so the interface can be tested without external AI calls. Add a server-side GEMINI_API_KEY to enable real AI-generated plans. Generated suggestions should always be reviewed by the user.
